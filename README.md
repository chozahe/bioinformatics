## Задания

### Задание №1 — Поиск длиннейшей ORF

Генерация случайной ДНК с заданным GC-составом и поиск самой длинной ORF
(Open Reading Frame) во всех 6 рамках трансляции.

**Использование:**
```bash
cd task1 && python3 orf_finder.py
```

Программа запросит:
- **Длину ДНК** (100–1000 нуклеотидов)
- **GC-состав** (20–80%)

После ввода программа:
1. Генерирует случайную ДНК с заданными параметрами
2. Ищет ORF во всех 6 рамках (3 прямой + 3 обратной цепи)
3. Находит самую длинную ORF с длиной белка ≥ 10 аминокислот
4. Выводит: триплеты ORF, транслированный белок, позиции

**Проверка:** https://www.ncbi.nlm.nih.gov/orffinder/
